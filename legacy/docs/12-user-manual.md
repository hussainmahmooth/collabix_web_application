# Collabix User Manual

1. **Sign Up**: Go to `/register` and create an account.
2. **Dashboard**: View project progress bars, active workloads, and quick AI insights.
3. **Tasks**: Track work in List or Kanban board views, toggle statuses via task detail actions.
4. **Channels**: Join text-chat streams or direct message teammates.
5. **AI Chat**: Type questions like "What tasks are overdue?" to get immediate workspace summaries.\n
