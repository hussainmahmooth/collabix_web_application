# Collabix — Project Overview

Collabix is a production-grade web-based team collaboration and task management platform, inspired by linear and Jira workflows. It features a custom blue-and-yellow SaaS design system.

## Primary Purpose
Enable teams to manage workspaces, create projects, assign task columns, communicate in chat channels, monitor calendar milestones, and receive notifications in real-time. It integrates Google Gemini AI to answer context-aware workspace questions.\n
