# Database Schema & ERD

## Primary Tables
- `profiles`: Extension of auth.users.
- `workspaces`: Workspace entities.
- `workspace_members`: User assignments inside workspaces.
- `projects`: Workspace project boards.
- `project_members`: User assignments inside projects.
- `tasks`: Work items with statuses and priorities.
- `task_assignees`: Tasks assignees maps.
- `labels` & `task_labels`: Workspace tags.
- `channels` & `messages`: Chat rooms structure.
- `notifications`: Notifications feed logs.
- `calendar_events`: Workspace calendar schedules.\n
