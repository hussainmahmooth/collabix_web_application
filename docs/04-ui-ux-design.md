# UI/UX Design System

## Brand Colors
- **Primary Blue**: `#2563EB` (Tailwind `blue`)
- **Dark Navy**: `#0B1220` (Tailwind `navy`)
- **Accent Yellow**: `#FACC15` (Tailwind `yellow`)
- **Background**: `#F7F9FC` (Tailwind `bg`)

## Themes
Supported Light/Dark modes using Tailwind CSS selector `.dark` and local storage indicators.

## Breakpoints
- **Mobile**: `320px` to `768px` (Navigation collapses to sliding sidebar).
- **Tablet/Laptop**: `768px` to `1024px` (Sleek icon-only sidebar).
- **Desktop**: `1440px+` (Full sidebar width, grids expand to multiple columns).\n
